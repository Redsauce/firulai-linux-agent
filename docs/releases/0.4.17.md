# Firulai Security Agent 0.4.17

Adds bounded observations of package-owned executables for Debian/Ubuntu dpkg inventories. Each observation records the owning binary package, exact installed version, collection time, and whether the executable file was observed on disk. Programs are not executed.

The collector preserves existing package and source identities. Ambiguous multi-architecture ownership is skipped; missing Python or unreadable manifests do not interrupt inventory. Missing or truncated evidence never proves software absence.

This release supplies evidence for the shared importer and matcher. It does not itself change vulnerability states. Installed agents must update and complete an inventory scan before RSM receives the new observations.
