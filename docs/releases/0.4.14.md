# Firulai Security Agent 0.4.14

Preserves the complete installed binary and source package versions reported by
dpkg, including distribution revisions needed to check vendor security fixes.
Real binaries are retained even when their names match their source packages;
removed packages and configuration-only records are excluded.

RubyGems bundled versions no longer include the `default:` metadata marker.
Package manager identity and the distinction between binary and source versions
are retained. The existing update path preserves agent configuration and UUID.

The RSM inventory receiver must retain same-name dpkg binaries. A fresh
inventory is required before the matcher can use the additional evidence.
This release does not by itself change vulnerability states.
