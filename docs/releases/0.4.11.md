# Linux 0.4.11: aviso de recopilación

Las ejecuciones manuales y programadas reportan inicio, heartbeat cada 45
segundos y fin al terminar el envío o salir con error. Firulai muestra
«Recopilando datos» en listado y detalle, sin estado final de completado.

El reporte es opcional, tiene timeout y no sigue redirecciones con credenciales.
Un backend antiguo o sin conexión no impide recopilar ni enviar el inventario.
La caducidad de tres minutos retira avisos de procesos interrumpidos.

Funciona con y sin root y conserva UUID, configuración y planificación. Requiere
el endpoint `/api/agents/collection-status` del backend de Firulai. Los objetos
RSM existentes no necesitan nuevos cambios.
