# Firulai Security Agent 0.4.15

Inventory includes the observed kernel family from `uname -s` alongside the
existing kernel release and architecture. A failed observation remains empty;
the agent does not infer the kernel family from the distribution name.

Snap inventory retains revision, tracking channel, publisher and notes as
inventory evidence, using a stable command locale. Existing package versions
and collection behavior are preserved.

The receiver and matcher consume this evidence through the shared workflow.
Publishing this release does not itself change vulnerability states: installed
agents must update and upload a fresh inventory first.
