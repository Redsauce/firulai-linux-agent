# Linux 0.4.5

The inventory reports the Linux agent installation mode (`root` or `user`) and
the installation owner. New installations persist both values in the private
configuration; existing installations infer the owner from the installed script.

RSM stores the optional metadata in System properties 1991 and 1992. Firulai
uses it to show the appropriate uninstall command. Agents without metadata keep
the existing manual choice. Windows agents are unchanged.

This release contains only installation metadata reporting. It does not include
pending agent uninstallation lifecycle changes or immediate version reports.
