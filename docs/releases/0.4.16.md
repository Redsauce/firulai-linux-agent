# Firulai Security Agent 0.4.16

Includes the kernel-family and Snap inventory evidence described in 0.4.15.
The installer, main agent and compatibility updater entry all select 0.4.16.
This preserves migration from installations using the old `rs-agent` name.
A regression test checks that these three entry points use the same version.

0.4.15 was superseded before activation in the Firulai update catalog after
CI detected that its compatibility entry still selected the previous release.
