# Linux 0.4.12: mensajes de suscripción

El rechazo distingue agente no activo de ausencia de suscripción activa y
evita el término «cobertura» en los diez idiomas. Ambos casos se detienen
antes de recopilar o enviar datos. No cambia la identidad, configuración,
reporte de recopilación ni programación de instalaciones root o de usuario.

El instalador usa el tag 0.4.12. Se conserva la comprobación de actualizaciones
sin suscripción; no autoriza un inventario ni una activación automática.
