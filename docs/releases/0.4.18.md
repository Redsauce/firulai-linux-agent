# Firulai Security Agent 0.4.18

Adds bounded SHA-256 observations of installed dpkg-owned command files, together with architecture and complete binary/source versions. The collector reads files without executing programs, downloading reference packages or installing dependencies.

The existing `inventory_evidence` schema-1 command observation remains available to current receivers. The additive `installed_file_evidence` schema-2 field carries the measurements for the updated receiver. Upgrading the agent before the receiver therefore preserves existing command evidence.

Command coverage is collected before optional hashes, so hashes cannot displace already observed commands within the payload limit. Measurement is bounded globally to 256 files, 96 MiB and a two-second budget checked between reads, with an 8 MiB per-file limit. Symlinks and files that change during reading provide no hash. Missing Python or exhausted limits preserve inventory without claiming verified absence or identity.

This release supplies evidence only. Matching a hash requires an authenticated reference of the exact package version and architecture. No vulnerability is opened, fixed or removed by the agent. Installed agents must update and complete inventory before any installed-file evidence can be verified in RSM.

Publication alone does not change the version selected by the Firulai update catalog. Windows agent changes are not included in this Linux release.
