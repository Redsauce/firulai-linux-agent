# Linux 0.4.4

Release de comprobacion de la actualizacion automatica desde 0.4.3.
El unico cambio del agente respecto a 0.4.3 es `AGENT_VERSION`.

Se conserva la configuracion, UUID, token, estado y planificacion. La prueba
publicada ahora permite seleccionar version origen y destino mediante
`FROM_VERSION` y `TO_VERSION`, con valores predeterminados 0.4.3 y 0.4.4.

El equipo `apps`, instalado con root y actualizacion automatica habilitada,
debe detectar 0.4.4 al ejecutar el agente, descargar los scripts desde el tag
concreto, reiniciar y enviar el inventario. Esta comprobacion en el servidor
queda pendiente de la salida facilitada por el usuario.
